Overview

Translate a standard description once, and every part that uses it follows.

This module automatically translates the product name and description into all the languages installed on Odoo. It is useful when you use the standard descriptions of OdooPLM and you need the name translations of your products to stay up to date.

Part descriptions are not free text: they repeat. Hexagon head screw, bearing housing, cover plate. Translating them one product at a time is work that grows with the catalogue and is never finished, because every new part starts the job again.

What it does

Translate the standard description

The translation is done once on the standard description, in the languages installed on the system, and it is that entry that carries the words.

The products follow

Setting the standard description on a product brings the translations with it, so the name and the description exist in every language without anyone opening the product in each of them.

Kept up to date

When the standard description changes, the products that use it are not left behind with a wording that no longer matches.

Where it pays off

The gain grows with the catalogue and with the number of languages: a documentation set, a spare parts manual or a bill of material printed for a foreign subsidiary comes out translated because the parts already are.
