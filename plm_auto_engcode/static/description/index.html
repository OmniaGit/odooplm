Automatic Part Number

Overview

Part numbers issued by the system, in the series the category dictates.

This module assigns the part number of a new item automatically, taking it from a numbering sequence attached to the product category.

Part numbering is the one convention a technical office cannot afford to lose control of, and the one most often left to people. Somebody keeps the register in a spreadsheet, somebody else is on holiday, two designers take the same number on the same morning, and a year later nobody can say which series a code belongs to.

What it does

A series per category

Each product category carries its own numbering sequence, so castings, sheet metal parts and purchased components are numbered in separate series that say something about the item just by looking at it.

Assigned when the category is chosen

Choosing the category of a new part draws the next number of that series. The designer does not consult a register and does not ask a colleague which number is free.

It does not renumber what exists

As long as the category stays the same the code stays the same: the number is issued once. Only a change of category, which means a change of series, draws a new one.

A general series as a fallback

A category with no sequence of its own falls back on the general part number sequence, so the numbering never stops because somebody forgot to configure a branch of the catalogue.

  • ▪  Part numbers drawn from a sequence, not from a register
  • ▪  A different series per product category
  • ▪  Issued once, on the category of the new item
  • ▪  A general sequence when a category has none
