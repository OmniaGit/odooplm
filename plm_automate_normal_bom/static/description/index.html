Overview

Every released part gets its manufacturing structure, without anyone remembering to create it.

This module creates the normal bills of material for all released products that do not have one yet, through a scheduled action or on demand.

The engineering structure is created by the CAD upload; the manufacturing one is created by a person, in a second moment, when there is time. Between the two moments a part is released and has no structure to build with, and the gap shows up in the worst place: when production tries to launch an order.

What it does

It looks for what is missing

The released products that carry no normal bill of material are found by the system, so the omission does not have to be noticed by somebody.

Derived from the engineering structure

The manufacturing structure is generated from the engineering one, which is the point of having kept the two distinct: the design is not retyped, it is transformed.

Every five minutes, or on request

A scheduled action passes regularly and fills the gaps, so the delay between a release and a usable structure is minutes rather than the next time somebody looks. The same can be run on a chosen set of products when a release cannot wait.

Errors are reported, not swallowed

What could not be generated is logged with its reason, so a structure that failed to build is a message rather than a silence you discover in production.

  • ▪  Released products without a manufacturing BOM are found automatically
  • ▪  The structure is derived from the engineering one
  • ▪  Scheduled every few minutes, or run on demand
  • ▪  Failures logged with their reason
