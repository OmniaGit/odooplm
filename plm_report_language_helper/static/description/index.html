Report Language Helper

Overview

The same bill of material, printed in the language of whoever receives it.

When you have to print reports in different languages and you need a faster tool to manage it, this module lets you do exactly that. Through a simple wizard it extends the capability of your PLM module to produce PDFs in different languages.

A supplier in Poland, a subsidiary in Brazil, a customer who requires documentation in his own language: the content is the same structure, only the words change. Producing it by switching the interface language, printing, and switching back is a procedure people get wrong on a Friday afternoon.

What it does

From the parts you already selected

From Search on Engineering Parts select a product, then use the action menu: Create report spare bom or Create Boms report. The report starts from the selection, not from a separate screen.

Language chosen at print time

The wizard asks for the options you prefer, the language among them, and produces the document accordingly. The interface language of the user stays where it is.

The PDF is downloaded, not searched for

Once created, the file is downloaded from the wizard itself, so the document reaches the person who asked for it without a trip through the attachments.

Both structures covered

Manufacturing bills of material and spare part ones are both printable this way, which matters because the spare documentation is the one that travels furthest from home.
