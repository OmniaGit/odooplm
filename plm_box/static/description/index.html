Box

Overview

The shared drive your company already needs, inside Odoo, on Odoo's own documents.

Box is a document area built into Odoo: folders, files, access rights and versions, the way a file sharing service works, except that the files are ordinary Odoo attachments and they live in the same database as the business records they belong to.

Every company runs a second archive next to the ERP. A Dropbox for the offer documents, a SharePoint for the quality certificates, a network drive for everything else. It works until somebody has to answer a simple question — which certificate went with that order, which version of the specification the customer signed — and the answer is in a folder whose name only one person knows.

What it does

Folders that behave like folders

Boxes contain documents and other boxes, nested as deep as your organisation needs. It is the structure people already have on the shared drive, so nobody has to be taught a new way of filing.

The files are Odoo attachments

There is no second storage and no synchronisation to keep alive: a document in a box is a standard Odoo attachment, with the search, the access rights and the backups that already apply to every other document in the system.

Attached to the work, not to a path

A box can be linked to the products, the projects, the tasks, the sale orders, the bills of material and the work centres it concerns. The certificate is reachable from the order, and from the part, instead of from a folder name somebody has to remember.

Under revision, like everything else in PLM

Boxes follow the engineering workflow: draft, confirmed, released, obsolete, and back again when needed. A released set of documents is a fixed set, and the next version does not overwrite what a customer already received.

Check out before you edit

Documents are checked out and checked back in, so two people cannot quietly overwrite each other's work, which is the failure mode every shared drive has and nobody notices until it costs a day.

Access by group

Which groups may see a box is part of the box, so the commercial documents and the engineering ones can live in the same system without living in the same hands.
