Automatic Weight

Overview

Product weight computed from the bill of material, from the CAD, or set by hand.

This module computes the product weight from the normal bill of material calculation, using the CAD weight or a custom weight you set.

Weight is one of those figures that everyone assumes somebody else maintains: it ends up on the transport document, in the quotation, in the structural check. Here it is computed from the data already in the system, and you decide which source to trust for each product.

What it does

Computed on the structure

From Search on Engineering Parts select one or more products, then run the Compute Bom Weight action from the action menu. The weight of the bill of material is computed and the NBOM Weight Computed field is filled in.

Three ways to resolve it

Once the weight is computed you decide, product by product, how it has to be used: the net weight alone, the weight coming from the CAD, or the one computed from the normal bill of material.

Use Net Weight

In the production step only the gross weight is used.

Use CAD Weight, or the BOM

With Use CAD Weight the CAD weight is added to the additional weight and the result is set as gross weight. With Use Normal Bom it is the computed BOM weight that is added to the additional weight, and the result set as gross weight.

The action menu on the engineering parts: Compute Bom Weight runs on the selection.

The computed weight of the structure, written to NBOM Weight Computed.

Product by product, which source the weight is taken from.

  • ▪  Weight computed from the normal bill of material
  • ▪  CAD weight and additional weight taken into account
  • ▪  The source chosen per product, not globally
  • ▪  Run on a selection, from the action menu
