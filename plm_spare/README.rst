PLM Spare
=========

Add Spare BOM management and spare-parts manual generation to OdooPLM.

Overview
--------

Spare parts catalogues are a critical deliverable for after-sales support.
This module introduces the **Spare** BOM type alongside the existing
Engineering and Normal BOM types. Spare BOMs can be maintained independently
of the manufacturing BOM and are used to generate spare-parts manuals and
reports.

Key Features
------------

* New BOM type: **Spare** — dedicated to spare-parts catalogues
* Spare BOMs live alongside Engineering and Normal BOMs on the same product
* Report generation for spare-parts manuals
* Foundation for ``plm_report_language_helper`` multi-language spare reports

Dependencies
------------

* ``plm`` — OdooPLM core module
