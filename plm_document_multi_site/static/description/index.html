Overview

The same CAD documents in every plant, without waiting for the network.

This module allows the synchronization of your CAD documents across different sites. It helps to use the PLM module in a company with several sites worldwide, or with sites on a slow connection. To work properly it needs an OdooPLM file server installed.

A 3D assembly is heavy. Opening it from another continent over a company line is the difference between working and waiting, and it is the reason branch offices end up keeping their own copies, which drift from the master ones within a month.

What it does

A file server per site

Each site declares its own OdooPLM file server, so a designer takes documents from the machine next door instead of across the network, while the database stays single and shared.

Synchronisation you can audit

Every transfer is recorded. The history of a document says where it went, when, and whether anything is still pending, so a missing file is a question with an answer.

On demand, one document or many

A synchronisation can be run on a single document when somebody needs it now, or on a selection when a whole assembly has to reach another site.

Or on a schedule

The transfers can also run on their own, so the night moves the files and the morning finds them in place.
