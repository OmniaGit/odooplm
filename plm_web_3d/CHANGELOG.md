# Changelog – plm_web_3d Module

## 18.0.3.0.1 – 2026-03-10

### Added
- Markup Management System in 3D viewer:
  - Toolbar with Draw, Rectangle, Circle, Arrow, Text, Clear, Undo, Redo, Save, and Close buttons.
  - Undo/Redo functionality using FabricJS object state stack.
  - Send markup images as chatter messages to:
    - The document itself.
    - All linked components
