PLM Web 3D Viewer

An interactive browser-based 3D/2D viewer for CAD files embedded directly in Odoo PLM. Built on Three.js, it provides real-time inspection, measurement, markup, and assembly explosion — all without installing any desktop software.

Supported File Formats

ExtensionTypeNotes
.glb / .gltf3DGL Transmission Format — recommended for assemblies
.3mf3D3D Manufacturing Format with named components
.stl3DStereolithography mesh
.fbx3DAutodesk FBX
.obj3DWavefront OBJ
.wrl3DVRML
.stp / .step3DAuto-converted to 3MF on first open (requires plm_automated_convertion)
.dxf2D2D drawing — rotation disabled, 3D scene elements hidden
.svg2DScalable Vector Graphics
.json3DThree.js JSON scene

Toolbar

A transparent icon toolbar sits in the upper-left corner and is always visible. Each button has a tooltip on hover.

Features

Loading Progress Bar

Frosted-glass overlay shows file name, animated progress bar, and percentage while any format is loading.

Hover Highlight

Hovering a part colours it pink and adds wireframe edges (Odoo purple). After 1 second the part name tooltip appears, fetched from Odoo.

Sidebar Sync

Hovering a part in the 3D scene highlights and auto-scrolls to the matching entry in the document tree panel on the right.

Measure Tool

Click two snap points to measure the distance. The label tracks the cursor in real time and shows the final distance in mm at the line midpoint.

Explosion View

Slider explodes the assembly outward from the global bounding-box centre. Displacement is proportional to the max dimension of the assembly.

Markup System

Draw, annotate and submit screenshots with comments or Odoo activities directly from the viewer.

View Cube

3D orientation cube in the bottom-right corner. Click any face to snap the camera to Front, Back, Top, Bottom, Left or Right.

DXF 2D Mode

For DXF files, rotation is disabled, the floor plane / grid / axes helper are hidden, and 3D-only controls (background, lights, transparency, explosion) are removed from the settings panel.

Settings Panel

  • Background — technical grid, two room environments, outdoor, three workshop HDRIs
  • Light Settings — distance, three spot lights, camera light, ambient light
  • Transparency — global opacity slider
  • Color — global colour picker
  • Explosion — assembly explosion slider (0–100)
  • Markup Logs — list of saved markups with preview thumbnails

Technical Dependencies

  • Three.js — bundled in static/src/js/lib/three.js/
  • Fabric.js (CDN) — markup canvas drawing
  • Font Awesome 4.7 (CDN) — toolbar icons
  • Odoo module dependency: plm
STEP files: opening a .stp / .step attachment via the 3D Web button automatically converts it to 3MF on first access (requires the plm_automated_convertion module). The converted file is cached so subsequent opens are instant.
