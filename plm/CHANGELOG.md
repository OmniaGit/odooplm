# Changelog

## [19.0.1.0.3] - 2026-01-28

### Fixed
- Fixed an issue during **layout save** to ensure the layout and the related **3D model are always aligned**.
- Added a validation message in the **document view** when layout and 3D model alignment is not correct.
- Fixed issues in **BOM creation**.
- Improved the computation of **`must_update_from_cad`** to ensure correct CAD synchronization.

### Added
- Added new functionality to make the system **compatible with the new client download**.
- Introduced a **new download system** to support the updated client side download mechanism.
