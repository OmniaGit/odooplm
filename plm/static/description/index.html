Product LifeCycle Management

Overview

Integrates CAD Packages into Odoo, extending product, B.O.M and document capability.

The module is developed and maintained by OmniaSolutions, Further information at www.omniasolutions.website

Download the CAD Client

The OdooPLM client application bridges your CAD editor and your Odoo instance. It is available on SourceForge.

Download the CAD client
sourceforge.net/projects/openerpplm

Run it with Docker

OdooPLM is published as a ready to run Docker image, on GitHub Container Registry and on Docker Hub. A single command gives you Odoo with the whole community PLM suite in the addons path, a PostgreSQL database and a working PLM server on the first boot — no database wizard, no dependency installation.

git clone --branch 19.0 https://github.com/OmniaGit/DockerOdooPLM.git
cd DockerOdooPLM
docker compose up

Two variants

full carries the CAD conversion stack, for batch STEP to 3MF, STL and PNG conversion. slim leaves it out, for the teams that do not convert. Both ship every community PLM module in the addons path.

Demo images

Each variant also has a demo tag that boots already populated: a sample product over three BOM levels, its 3D models, ballooned assembly drawings and the spare parts manual that prints from them.

The images are rebuilt every week, against both the PLM sources and the official Odoo image, and every build is started and verified before it is published.

Features

This application enables a group of people to intelligently and efficiently manage 3D Models and 2D Drawings, directly from CAD editors. Helps to share 2D documents using PDF embedded. Puts your engineering decisions, models and drawings into Odoo.

It helps to work on Concurrent Engineering managing access policies on documents. Moreover, it adds many reports and views on Bill of Materials or related to them.

Try it online
odoo.sh/project/odooplm/builds

CAD Integrations

Fully Integrated on main commercial CAD/CAE Packages with a menu of commands.
Allows to assign Product informations to 3D Models / 2D Drawings, reads the BoM directly from graphic hierarchy structure.

Product LifeCycle Management

Manages fundamental revisions of Products and Documents. Integrates CAD Packages into Odoo extending product revision and B.O.M. capability. Allows to manage LifeCycle of Products and Documents, integrating it with standard Workflow tools.
Helps to describe history of changes maintaining BoM through revisions.
