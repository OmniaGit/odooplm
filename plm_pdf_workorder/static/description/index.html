PDF on the Work Order

Overview

The drawing on the shop floor screen, next to the work instructions.

This module adds to the work orders the ability to switch the preview from the routing worksheet to the 2D drawing, and back.

The operator has a screen showing the work instructions, and a drawing that lives somewhere else — printed on a sheet that is two revisions old, or on a shared folder nobody opens with oily hands. The information needed to do the job is split in two, and only one half is under revision control.

What it does

Two documents, one screen

The preview of the work order switches between the routing worksheet and the 2D drawing of the part, so the operator reads both without leaving the order.

The drawing is the current one

The drawing shown is the PLM document of the part, at the revision the PLM holds. What is on the screen follows the revision instead of following the printer.

Worksheet under control

From the routing tab the use of its worksheet when processing the work order can be enabled or disabled, so a routing that does not need a sheet does not impose one.

Only where it applies

This module is only available on the Enterprise version of Odoo, because it extends the shop floor work order interface that ships there.
